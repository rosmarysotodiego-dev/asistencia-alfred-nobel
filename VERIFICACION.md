# Verificación de la entrega

Código ejecutado con PHP 8.3 y MariaDB 10.11 en una base de pruebas aislada.

- Instalador: conexión, creación de base y administrador
- Login solo con usuario y contraseña; sesión y lectura de base
- Docentes: alta, consulta, edición, horas con segundos y validación de cruces
- Estudiantes y asistencia: generación de código, rechazo de código inválido y marcación válida
- Usuarios: credenciales automáticas, permisos de consulta y desactivación inmediata
- Eliminación de docente, estudiante y asistencia; bitácora transaccional
- Cierre de sesión e invalidación del token

La instalación en tu XAMPP requiere completar el instalador con los datos de tu MySQL. No se incluyen datos de prueba, credenciales del sitio alojado ni una base ya configurada.
